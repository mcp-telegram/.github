# Getting help

You can write in any language.

- **How do I…?** Start with the docs: [mcp-telegram.github.io/mcp-telegram](https://mcp-telegram.github.io/mcp-telegram/) for self-hosting and [mcp-telegram.com/docs](https://mcp-telegram.com/docs/quickstart) for the hosted version. Questions and ideas go to [Discussions](https://github.com/mcp-telegram/mcp-telegram/discussions).
- **Something is broken in a tool, the CLI or the daemon:** [open an issue in mcp-telegram](https://github.com/mcp-telegram/mcp-telegram/issues/new/choose).
- **Something is broken on mcp-telegram.com (login, OAuth, settings):** [open an issue in mcp-telegram-cloud](https://github.com/mcp-telegram/mcp-telegram-cloud/issues/new/choose).
- **Security problem:** see [SECURITY.md](SECURITY.md). Never in a public issue.
- **What is planned:** the public [roadmap board](https://github.com/orgs/mcp-telegram/projects/1).

mcp-telegram is maintained by one person in spare time. We usually reply within a few days; there is no paid support.
